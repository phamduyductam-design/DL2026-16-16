# Dataset information and reproduction

This project uses two public datasets. The image files are not redistributed in this repository. The committed CSV manifests identify every selected source image and record its SHA-256 hash. Image resizing and cropping happen when the code reads an image; no separate processed-image dataset is created.

## Official sources and versions

| Dataset | Version used | Official source | Role |
|---|---|---|---|
| Imagenette | Imagenette2-160, the revised 160-pixel release with the post-December-2019 official train/validation split | [fastai dataset page](https://github.com/fastai/imagenette), [imagenette2-160.tgz](https://s3.amazonaws.com/fast-ai-imageclas/imagenette2-160.tgz) | Training, validation, and in-domain testing |
| Oxford-IIIT Pet | Original Oxford-IIIT Pet release associated with Parkhi et al. (2012); the publisher does not assign a numbered version | [Oxford VGG dataset page](https://www.robots.ox.ac.uk/~vgg/data/pets/) (download both images.tar.gz and annotations.tar.gz) | Out-of-domain testing only |

Place the downloaded files under the repository root as follows, or edit the two root paths in configs/datasets.yaml:

~~~text
datasets/
  imagenette2-160.tgz
  Oxford-IIIT-Pet/
    images/
    annotations/
      test.txt
~~~

The Imagenette reader accepts either the archive above or an extracted directory containing the official train/ and val/ folders. The Pet reader requires extracted images/ and annotations/ directories. Download the datasets from their publishers; do not substitute a different release or an unrelated train/test split.

## Fixed experimental splits

The data-selection seed is 2026. The locked selections and their hashes are in data/manifests/ and data/manifests/audit.json.

| Selection | Source partition | Selection rule | Images |
|---|---|---|---:|
| Imagenette training | Official train | 600 images from each of 10 classes | 6,000 |
| Imagenette validation | Official train, disjoint from training | 30 images from each of 10 classes | 300 |
| Imagenette test | Official val | 100 images from each of 10 classes | 1,000 |
| Oxford-IIIT Pet test | Official annotations/test.txt | 13 or 14 images per breed across 37 breeds | 500 |

Pet images are never used to train, select a checkpoint, or tune hyperparameters. The code rejects unreadable images and removes exact byte duplicates before selection. It also screens for near duplicates using a perceptual hash followed by a small RGB-thumbnail comparison. This screening is approximate; it does not prove that every semantic duplicate has been removed. The audit file records exclusions and the exact policy.

## Image and mask preprocessing

1. Decode each image as RGB.
2. Resize it so its shorter side is 144 pixels while preserving aspect ratio.
3. For training, take a seeded random 128 x 128 crop and apply a horizontal flip with probability 0.5. For validation and testing, take the centered 128 x 128 crop.
4. Convert RGB values to floating-point numbers in [0, 1].
5. Generate a binary missing-region mask. The four patterns are center rectangle (C), random rectangle (R), free form (F), and six separate holes (H), each at target missing areas of 15%, 30%, and 50%. Training masks are generated by a fixed seed schedule. Validation and test masks are stored in reproducible banks using mask seed 314159 and generator version 2.0.0. Within one image and target area, the four patterns differ in actual masked area by at most one percentage point.

Both models use the same manifests, preprocessing, and fixed evaluation masks. An image's SHA-256 value is checked when it is read. The files in data/manifests/ are the downloadable record of this project's selected image lists; the source images themselves remain available from the official links above.

## Scripts to reproduce the data

Install dependencies as described in README.md and place the original datasets at the paths above. The committed manifests are already locked, so a normal reproduction starts by validating them and rebuilding the mask banks:

~~~powershell
python scripts/build_mask_bank.py --config configs/base.yaml
~~~

The command validates all four manifests against the original images, checks the mask generator, and creates fixed banks for Imagenette validation, Imagenette test, and Pet test. It does not create a new dataset release.

To independently regenerate the CSV selections, copy configs/datasets.yaml to a separate configuration file, change only manifest_dir to a new empty directory, and run:

~~~powershell
python scripts/prepare_data.py --config path/to/separate_datasets_config.yaml
~~~

Compare the four regenerated CSV hashes with manifest_sha256 in data/manifests/audit.json. The script intentionally refuses to overwrite the committed manifests. The complete training and evaluation sequence is in README.md and scripts/run_experiment.py.
